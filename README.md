# ServiceNow Institution Details Project

## Project Description
This project is built in ServiceNow for managing Institution Details table (u_institution_details).

## Features
- Created custom table u_institution_details
- Configured ACLs (Access Control Rules)
- Fixed Security Constraints issue
- Added fields: Institution Name, Code, Location

## Tables Used
- u_institution_details

## How to Use
1. Login to ServiceNow
2. Go to Institution Details table
3. Create new records

## Technologies
- ServiceNow
- JavaScript (Glide API)
- ACL Scripting
